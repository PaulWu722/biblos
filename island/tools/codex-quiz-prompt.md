你要替「信息島」閱讀遊戲出題。只新增檔案，不要修改任何既有檔案。

## 範圍
文章在 `../docs/data/<書>/<篇>.json`（欄位 `t` 是標題，`b` 是全文）。
這一批：書 lee、nee、nt、lsnt、lsot，各取篇號 0 到 9（共 50 篇）。

## 輸出
每篇一個檔案：`public/quiz/<書>/<篇>.json`，格式：
```json
{"questions":[
  {"q":"題目","options":["選項A","選項B","選項C"],"answer":1,"ref":"出處"},
  {"q":"題目","options":["選項A","選項B","選項C"],"answer":0,"ref":"出處"}
]}
```
- 每篇剛好 2 題，每題 3 個選項，`answer` 是正確選項的索引（0、1、2），兩題的正確位置不要都一樣。
- 繁體中文。用詞照文章原文（例如「神的經綸」「分賜」「召會」），不要改寫成其他譯本的用語。

## 出題規則
- 只能根據這一篇的內文出題，讀過這篇的人一定答得出來；不要考文章沒講的背景知識。
- 考信息的重點（中心思想、關鍵說法），不要考數字、人名拼法或細枝末節。
- 錯誤選項要合理但明確是錯的，不能和正解意思相近到有爭議。
- `ref`：如果題目的答案出自文章裡引用的某處經文，寫那處經文，照文章的寫法（例如「耶利米書二章十三節」）；否則寫「本篇信息」。經文出處一定要是文章裡真的有出現的，不可自己推測。

完成後只回報：產生了幾個檔案、有沒有哪篇出不了題（例如內文太短）以及原因。
